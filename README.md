This is an optimized version of BedrockOffhand, updated to provide flawless compatibility with custom item plugins. The original plugin occasionally stripped NBT tags, custom lore, and item attributes when swapping items between hands. This fork ensures that all NBT data is perfectly preserved during the swap while preventing visual desyncs in the client.

Whether you are running EliteMobs, MMOItems, MythicMobs, Oraxen, or ItemsAdder, your custom weapons, gear stats, and 3D models will remain completely intact when using the offhand mechanic.
